# Close out honestly

Inspect the actual final source and remote state when available. Bind any merged claim to an observed merge and target commit. If access is missing, report it; do not infer merge from a local branch or a review result.

Compare delivered scope against accepted outcomes. Separate completed, descoped by decision, deferred and unresolved work. Identify evidence for each load-bearing claim. Stale candidate evidence cannot satisfy current acceptance.

Report validation actually run, review state, manual/runtime gaps, compatibility or data boundaries, blockers with clearing actions, and rollback for consequential outward actions. A stopped or refuted outcome is valid; do not widen scope to force success.

Reconcile current-state pointers only within the authorized scope. Keep detailed chronology on historical records. Do not close an issue with outstanding acceptance unless its disposition is explicit and appropriate.

Inventory dirty/committed/pushed/merged state and retained workspaces/artifacts. Preserve uncertain, dirty or unmerged work. Inventory is not deletion permission. If an active extension owns closeout or cleanup, use its interface rather than compete with it.

Return a concise self-contained handoff with the next authorized action. Do not claim user-visible completion when the required observation remains unavailable.
