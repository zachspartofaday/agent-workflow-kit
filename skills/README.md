# Portable skills

Copy an individual folder, retaining its internal references. No skill requires a private repository, another installed skill or this catalog. Use your host’s supported skill-loading mechanism.

| Skill | Capability |
| --- | --- |
| [adapt-repository-docs](adapt-repository-docs/SKILL.md) | Inspect and adapt existing repository documentation to a coherent agent workflow while preserving local conventions and stronger requirements |
| [coordinate-work](coordinate-work/SKILL.md) | Coordinate a bounded engineering task through inspection, planning, implementation, validation, review and handoff |
| [write-program-docs](write-program-docs/SKILL.md) | Author a proportional requirements, plan and current-state document set for multi-step or coordinated work |
| [prepare-kickoff](prepare-kickoff/SKILL.md) | Prepare a bounded implementation kickoff for one ready issue or program slice using current source and predecessor evidence |
| [review-change](review-change/SKILL.md) | Review a specific change and manage finding resolution against its current candidate |
| [closeout-work](closeout-work/SKILL.md) | Reconcile delivered or stopped work with current source, validation, review and outstanding acceptance |
| [audit-repository](audit-repository/SKILL.md) | Perform an evidence-based repository audit focused on consequential risks and useful findings |
| [maintain-docs](maintain-docs/SKILL.md) | Audit and repair documentation ownership, current-state drift and broken references within the requested scope |
| [design-workflow-extension](design-workflow-extension/SKILL.md) | Design a Pi workflow extension from adopted repository rules and demonstrated coordination problems |

Skills guide judgment. If an active extension owns a mechanism, use its interface instead of running a competing controller.
