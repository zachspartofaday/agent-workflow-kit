# Working on this kit

This repository owns an educational workflow, original generic skills, and a Pi teaching extension. It does not own or depend on the author's private runtime or product repositories.

Read the accepted task, then the relevant guide in [docs/INDEX.md](docs/INDEX.md). [CONTRIBUTING.md](CONTRIBUTING.md) owns exact validation commands. Preserve unrelated user changes. Keep the teaching example deliberately small and its claims limited to tested behavior.

Docs and operator intent define requirements; skills and extensions cannot grant themselves additional authority. Keep actual results separate from model reports and fixture demonstrations. Do not introduce private implementation, credentials, sessions, local paths or proprietary examples.

Edit the narrow owner of a fact. Keep demo behavior synchronized with its walkthrough and contracts. Verify diagrams visually after changing them. Each portable skill must remain usable when copied alone. Never depend on a personal skill installation.

Publication, package release and global agent configuration are separate actions. Test the extension in an isolated session, without another workflow controller.
